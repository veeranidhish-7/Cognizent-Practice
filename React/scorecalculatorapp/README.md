# scorecalculatorapp

Lab: Create a function component "CalculateScore" that accepts Name,
School, Total and goal (number of subjects) as props, calculates the
average score, and displays it.

## How to run
1. Unzip this folder.
2. Open the folder in VS Code (or open a terminal inside it).
3. Install dependencies:
   npm install
4. Start the app:
   npm start
5. Browser opens automatically at http://localhost:3000

## Notes
- Sample values (Name, School, Total, goal) are passed as props from
  App.js — edit them there to try different students.
- Styles live in src/Stylesheets/mystyle.css and are imported into
  CalculateScore.js.
