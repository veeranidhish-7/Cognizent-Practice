# StudentApp — Student Management Portal

Lab: Create Home, About, and Contact class components, each displaying
a welcome message, and render all three from App.js.

## How to run
1. Unzip this folder.
2. Open the folder in VS Code (or open a terminal inside it).
3. Install dependencies:
   npm install
4. Start the app:
   npm start
5. Browser opens automatically at http://localhost:3000
